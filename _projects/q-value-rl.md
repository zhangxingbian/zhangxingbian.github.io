Implemented and compared various Q-value based deep reinforcement learning algorithms on Atari game environments, including:

- **DQN** (Deep Q-Network)
- **Double DQN** — addressing overestimation bias
- **Dueling DQN** — separating value and advantage streams

A fun course project exploring the foundations of deep reinforcement learning.
